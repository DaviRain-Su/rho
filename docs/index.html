rho (ρ)

A Pi-style coding agent for the terminal, written in Rhombus. The kernel stays small; user-visible features load as extensions.

raco pkg install https://github.com/DaviRain-Su/rho.git
racket src/main.rhm
  • question, fetch, git checkpoints, MCP, plan/todo, sandbox, dashboard — bundled extensions
  • --no-extensions skips those plugins (no MCP connect)
  • Racket catalog source: github://github.com/DaviRain-Su/rho/v0.2.0
  • Full notes and providers: README
